# 个人知识库 PRD - 阶段 P0（核心可用）

版本：v1.0
日期：2026-01-23

## 1. 阶段目标
- 建立“可入库、可检索、可引用”的最小可用闭环。
- 覆盖多路径入库、白名单过滤、解析/OCR、向量+BM25 检索、问答与引用。

## 2. 范围（P0 必做）
### 2.1 入库与路径
- 入库路径必须是 Win10/Linux 绝对路径（不复制到项目内）。
- 仅白名单类型入库，非白名单记录为“未入库”。
- 生成入库清单（已入库/未入库 + 原因）。
- 维护 `data/manifest/kb_paths.json`，实现“source_root_path → kb_id”追溯。

### 2.2 解析与 OCR
- PDF/Word/Excel/txt 解析。
- 图片/扫描 PDF 走 OCR。
- 解析失败记录错误状态。

### 2.3 切分与索引
- 结构化切分优先，长度兜底（chunk_size + overlap）。
- 向量索引 + BM25 混合检索。

### 2.4 检索与问答
- Top-K 检索，回答带引用（文件名 + 页码/段落）。
- 引用包含 `source_deleted` 字段。
- 未命中时返回“无法从知识库中找到依据”。

### 2.5 增量策略（与 8.1 口径一致）
- 新增文件：追加索引。
- 变更文件（mtime/hash 变化）：删除旧索引后重建该文档索引。
- 删除文件：仅标记“源文件已删除”，保留索引与解析产物；回答时注明来源已删除。

## 3. 不包含（留到后续）
- token 级切分、多粒度索引、OCR 噪声清洗。
- 表格结构化增强（表头拼接、键值对转换）。
- UI 管理台、权限/加密、自动标签与 rerank。

## 4. 目录与存储（P0 落地）
- 原始文件：保留在用户指定系统路径。
- data/processed/<kb_id>/... 解析文本（可重建）。
- index/<kb_id>/... 向量索引 + BM25（可重建）。
- data/log/<kb_id>/... 日志与入库清单。
- data/manifest/<kb_id>/... 源文件清单与状态。

## 5. 验收标准（P0）
- 可入库 100+ 文件（含 PDF/Word/图片）。
- OCR 成功率 >= 90%（抽检）。
- 查询耗时 <= 5s（本地样例库）。
- citations 正常返回且包含 `source_deleted` 标记。

## 6. 风险与假设
- OCR 依赖外部服务稳定性。
- 模型质量影响检索与回答效果。
