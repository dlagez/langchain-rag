# 个人知识库 P0 - 目录设计（实现说明）

以下是按阶段 P0 PRD 落地的推荐目录结构 + 实现分层，已对齐：
- LLM：Bailian
- OCR：远程服务
- Embedding：优先本地服务（OpenAI 兼容 /v1/embeddings），未配置时回退 Bailian

P0 关键实现要点

1) 入库与路径
- 仅接受绝对路径；相对路径直接拒绝并记录为“未入库”。
- 白名单后缀过滤；不支持的类型写入未入库清单。
- 维护 data/manifest/kb_paths.json（source_root_path -> kb_id）。
- 输出 ingest_report.json（已入库/未入库/错误）。

2) 解析与 OCR
- PDF/Word/Excel/txt 解析；图片/扫描 PDF 走远程 OCR。
- 解析失败写入 manifest，并打 parse_error 状态。

3) 切分与索引
- 结构化切分优先，长度兜底（chunk_size + overlap）。
- 向量索引 + BM25 混合检索。
- Embedding 优先走本地服务：
  - LOCAL_EMBEDDING_BASE_URL
  - LOCAL_EMBEDDING_MODEL
- 未配置本地 Embedding 时回退 Bailian Embedding。

4) 检索与问答
- Top-K 检索 + 去重 + fusion。
- 回答带引用（文件名 + 页码/段落）。
- source_deleted=true 时在引用中标记。
- 未命中统一返回：无法从知识库中找到依据。

5) 增量策略
- 新增文件：追加索引。
- 变更文件：删除旧索引后重建该文档索引。
- 删除文件：仅标记 source_deleted=true，保留索引与解析产物。

环境变量（P0）

# LLM (Bailian)
BAILIAN_API_KEY=***
BAILIAN_MODEL=qwen-plus

# Embedding
# 本地 Embedding（优先）
LOCAL_EMBEDDING_BASE_URL=http://your-embed-host:8002/v1
LOCAL_EMBEDDING_MODEL=/path/to/bge-m3
# 回退 Bailian
BAILIAN_EMBEDDING_MODEL=text-embedding-v2

# OCR (remote)
OCR_URL=http://your-ocr-host/ocr
OCR_TIMEOUT=30
OCR_FILE_FIELD=file

# Chunking / BM25 / Qdrant
RAG_CHUNK_SIZE=800
RAG_CHUNK_OVERLAP=100
RAG_BM25_ENABLED=1
QDRANT_COLLECTION=kb_chunks
