# 个人知识库 PRD - 阶段 P1（稳定性与可追溯）

版本：v1.0
日期：2026-01-23

## 1. 阶段目标
- 强化可追溯性与稳定性，完善清单/日志/失败回溯。
- 提升入库与更新的可管理性。

## 2. 范围（P1 必做）
### 2.1 处理产物规范化
- 落地 `data/processed/<kb_id>` 目录规范：
  - `manifest.json`（doc_id、source_path、hash、status、updated_at、error）
  - `docs/<doc_id>/raw.txt`、`pages/`、`chunks.jsonl`、`meta.json`
  - `ocr/<doc_id>/page_0001.json`（可选）

### 2.2 配置变更追溯
- `kb_paths.json` 变更日志（时间、操作者、旧值/新值）。
- 白名单扩展配置记录（新增/移除扩展名）。

### 2.3 失败处理与重试
- 解析/OCR 失败重试策略（次数、间隔）。
- 失败文件进入“待处理/失败队列”，可手动重试。

### 2.4 统计与诊断
- 查询耗时、命中率、token 统计。
- OCR/解析失败清单导出。

### 2.5 入库方式增强
- 目录 watcher（可选开启）。
- 定期扫描调度（crontab/任务计划）。

## 3. 不包含（留到后续）
- UI 管理台
- 多粒度索引与 token 级切分
- 安全与加密

## 4. 验收标准（P1）
- 处理产物结构稳定、可复现。
- 失败文件可追溯可重试。
- 统计报表可输出 JSON/CSV。

## 5. 风险与假设
- 失败重试可能带来 OCR 服务压力。
- 处理产物存储空间增长显著。
