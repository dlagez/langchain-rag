# 个人知识库 PRD - 阶段 P2（体验与效果增强）

版本：v1.0
日期：2026-01-23

## 1. 阶段目标
- 提升检索质量、使用体验与安全性。
- 引入更高级的结构化处理与界面能力。

## 2. 范围（P2 必做）
### 2.1 切分与结构化增强
- token 级切分控制（替代字符计量）。
- 多粒度索引（段落/条款/章节并存）。
- 表格结构化增强（表头拼接/键值对）。
- OCR 噪声清洗（页眉页脚/水印/重复行）。

### 2.2 检索质量提升
- rerank 模型（可选）。
- 领域词表/同义词扩展。

### 2.3 体验与管理
- UI 管理台（KB 管理、入库状态、失败重试）。
- 自动标签与主题聚类。

### 2.4 安全与合规
- 索引/日志可选加密。
- 权限控制（基础角色）。

## 3. 验收标准（P2）
- 对复杂问题的引用准确率提升（基线对比）。
- UI 可视化入库与检索体验可用。
- 支持基础权限与加密存储。

## 4. 风险与假设
- rerank 与 UI 开发成本较高。
- 结构化增强依赖文档质量与 OCR 质量。
